# 🎈 Tiếng Anh 1 - Global Success Web App

Ứng dụng web học Tiếng Anh lớp 1 dựa trên bộ sách giáo khoa **Tiếng Anh 1 - Global Success**.

## 🌟 Tính năng chính
- **📚 16 Units bài học:** Đầy đủ từ vựng kèm hình ảnh minh họa, phiên âm chữ cái, mẫu câu giao tiếp và bài vè (Listen & Chant).
- **🔊 Phát âm tự động (TTS):** Hỗ trợ giọng đọc tiếng Anh cho học sinh tiểu học (click vào từ/câu/bài vè để nghe).
- **🎮 Trò chơi trắc nghiệm (Quiz):** Ôn tập từ vựng tương tác có tính điểm và hiệu ứng pháo hoa chúc mừng.
- **🎴 Flashcards thông minh:** Thẻ ghi nhớ 2 mặt (Tiếng Anh - Tiếng Việt) giúp ghi nhớ từ vựng dễ dàng.

## 🚀 Hướng dẫn chạy ứng dụng
Chỉ cần chạy lệnh sau để bật máy chủ tĩnh local:
```bash
bash start_server.sh
```
Sau đó truy cập link `http://localhost:3000` trên trình duyệt.
